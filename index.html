把字体带进 Readingo

  1. 导入 Readingo 笔记分享模板 ZIP，需包含 meta.json 和 HTML 入口。
  2. 选择 TTF、OTF、WOFF 或 WOFF2 字体，再切换“新字体”查看效果。
  3. 选择应用范围；默认全部文字，也可只替换正文与想法。
  4. 点击“嵌入字体并导出 ZIP”，在 Readingo 的分享模板导入入口选择下载的 ZIP，无需解压。

字体完整内置，不裁剪字库；导出保留原模板资源与内容接口，并压缩 ZIP。WOFF2 文件通常更小。此工具不会把 TTF 转换成 WOFF2。

部分字体缺少的汉字会使用备用字体。不同模板可用的想法、作者等字段由原模板决定。

兼容版会将字体内置在 HTML 中，并保留原模板的渲染与导出接口。旧 ZIP 不会自动更新。可以将旧 ZIP 再导入本站，自动读取其中的内置字体，重新导出兼容版，并在 Readingo 中使用新名称导入。
